CSV Analyzer

AI-powered CSV visualization & analysis

Python Streamlit Gemini Altair

An intelligent, interactive tabular data visualization web app. Upload any CSV file, ask questions in natural language, and let Gemini analyze the schema, follow a domain-specific charting skill, and generate interactive Altair charts — with self-healing code execution when something breaks.

What it does
  • Any CSV ingestion — upload files up to 10MB or pick from built-in sample datasets.
  • Automatic schema extraction — columns, types, null counts, and sample values without sending the whole dataset over the wire.
  • Skill-guided visualization — Gemini reads a dedicated charting skill to enforce chart selection, unit labeling, and non-null handling.
  • Self-healing execution — Altair code runs in an isolated namespace; failures are fed back to Gemini for an automatic repair attempt.
  • Interactive charts — responsive Altair output with hover tooltips and zoom/pan.
  • Code & trace transparency — inspect the generated Python and the agent's full tool-execution trace.
