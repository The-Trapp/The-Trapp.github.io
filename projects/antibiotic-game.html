Antibiotic Game

A bacteria vs. antibody strategy game

Python Released Windows · macOS · Linux

A turn-based strategy game about defeating resistant bacteria. Each bacteria is resistant to two antibodies (one is resistant to three) — the challenge is choosing the right combination to halve the population before it doubles on you.

How it works
  • Each turn, use or research one antibody.
  • Use two non-resistant antibodies → bacteria count halves.
  • Use one non-resistant + one resistant → count stays the same.
  • Use two resistant antibodies → count doubles.
  • Researching an antibody takes 4 turns, unlocking its upgraded version.
